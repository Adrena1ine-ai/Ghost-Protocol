## 📋 Пошаговая инструкция:

### Шаг 1: Убедитесь, что вы в git-репозитории

```powershell
# Проверьте
git status

# Если не git-репозиторий, инициализируйте:
git init
```

### Шаг 2: Установите git hook (один раз)

```powershell
ghost --install
```

Должно вывести: `✅ Hook Installed`

**Если видите "Not a git repo":**
- Выполните `git init` в корне проекта
- Затем снова `ghost --install`

### Шаг 3: Запустите фоновый режим

```powershell
ghost --ghost
```

**Что происходит:**
- Вы увидите: `👻 Ghost Protocol v1.0.1 Activated`
- Затем ничего не происходит - это **НОРМАЛЬНО**!
- Ghost работает в фоне и следит за файлами
- Оставьте этот терминал открытым (или сверните)

**Как проверить, что он работает:**
1. Создайте большой файл (например, изображение > 1MB) в проекте
2. Ghost автоматически добавит его в `.gitignore` и `.cursorignore`
3. Проверьте эти файлы - там должны появиться записи

### Шаг 4: Проверьте монитор (в другом терминале)

Откройте новый терминал и выполните:

```powershell
ghost --monitor
```

Вы увидите статистику проекта:
- Количество токенов
- Количество файлов
- Примерную стоимость API

---

## ⚠️ Важные замечания:

1. **"Ничего не происходит" - это нормально!**
   - Ghost работает тихо в фоне
   - Он не выводит сообщения при каждом изменении
   - Это сделано специально, чтобы не мешать работе

2. **Как понять, что Ghost работает:**
   - Создайте файл `test_big_file.bin` размером > 1MB
   - Ghost автоматически добавит его в `.gitignore`
   - Проверьте файл `.gitignore` - там должна быть запись

3. **Остановка Ghost:**
   - Нажмите `Ctrl+C` в терминале, где запущен `ghost --ghost`

## 🔍 Проверка работы:

### Тест 1: Создайте большой файл

```powershell
# Создайте тестовый файл > 1MB
fsutil file createnew test_big.bin 2000000

# Подождите 1-2 секунды
# Проверьте .gitignore
cat .gitignore | findstr test_big
```

Должна появиться запись `test_big.bin` в `.gitignore`

### Тест 2: Удалите файл

```powershell
# Удалите файл
del test_big.bin

# Подождите 1-2 секунды
# Проверьте .gitignore
cat .gitignore | findstr test_big
```

Запись должна исчезнуть из `.gitignore`

## 🆘 Если что-то не работает:

1. **Проверьте версию:**
   ```powershell
   pip show ghost-protocol
   ```
   Должно быть: `Version: 1.0.1`

2. **Если версия 1.0.0, обновите:**
   ```powershell
   pip install --upgrade ghost-protocol
   ```

3. **Если команда `ghost` не работает, используйте:**
   ```powershell
   python -m src --ghost
   ```
