# 📖 Инструкция по использованию Ghost Protocol

## 🎯 Вы находитесь в корне проекта, который нужно оптимизировать

### Шаг 1: Установка Ghost Protocol

Если еще не установлен:

```bash
pip install ghost-protocol
```

Проверьте установку:
```bash
ghost --help
```

---

### Шаг 2: Установка Git Hook (один раз)

Это настроит автоматическую проверку перед каждым коммитом:

```bash
ghost --install
```

**Что это делает:**
- Создает pre-commit hook в `.git/hooks/pre-commit`
- Блокирует коммиты с файлами больше 500KB
- Автоматически очищает `.gitignore` от удаленных файлов

**Результат:** Вы увидите `✅ Hook Installed`

---

### Шаг 3: Запуск фонового режима (основной режим работы)

Откройте терминал в корне вашего проекта и запустите:

```bash
ghost --ghost
```

**Что это делает:**
- Запускает фоновый процесс, который следит за изменениями файлов
- Автоматически добавляет большие файлы (изображения, видео, базы данных) в `.gitignore` и `.cursorignore`
- Удаляет записи из ignore-файлов, когда вы удаляете файлы с диска
- Работает тихо в фоне, не мешая работе

**Как использовать:**
1. Запустите команду
2. Сверните терминал (или оставьте его открытым)
3. Продолжайте работать над проектом как обычно
4. Ghost будет автоматически управлять ignore-файлами

**Остановка:** Нажмите `Ctrl+C` в терминале, где запущен ghost

---

### Шаг 4: Монитор (опционально)

В другом терминале (или после остановки ghost) можно открыть монитор:

```bash
ghost --monitor
```

**Что показывает:**
- Общее количество токенов в проекте
- Количество отслеживаемых файлов
- Примерную стоимость API (если использовать AI)
- Статус системы

**Остановка:** Нажмите `Ctrl+C`

---

## 🔄 Типичный рабочий процесс

### Первый запуск:

```bash
# 1. Установите hook (один раз)
ghost --install

# 2. Запустите фоновый режим
ghost --ghost
```

### Ежедневная работа:

1. **Запустите ghost в фоне:**
   ```bash
   ghost --ghost
   ```

2. **Работайте над проектом как обычно:**
   - Создавайте файлы
   - Удаляйте файлы
   - Делайте коммиты

3. **Ghost автоматически:**
   - Добавит большие файлы в `.gitignore` и `.cursorignore`
   - Удалит записи из ignore-файлов для удаленных файлов
   - Заблокирует коммиты с огромными файлами

4. **Проверьте статистику (по желанию):**
   ```bash
   ghost --monitor
   ```

## ⚙️ Настройка (опционально)

Создайте файл `ghost_config.json` в корне проекта:

```json
{
  "limits": {
    "max_asset_size_mb": 1.0,
    "max_code_size_mb": 0.5,
    "debounce_seconds": 0.5
  },
  "skip_dirs": ["my_custom_folder", "secrets"],
  "extensions": {
    "garbage": [".custom", ".mybigfile"],
    "code": [".mycode"]
  }
}
```

**Параметры:**
- `max_asset_size_mb` - размер в MB, после которого файлы автоматически игнорируются (по умолчанию: 1.0)
- `max_code_size_mb` - размер в MB, после которого код-файлы блокируются при коммите (по умолчанию: 0.5)
- `skip_dirs` - дополнительные папки для игнорирования
- `extensions` - кастомные расширения файлов

## 📋 Что делает Ghost Protocol автоматически:

### ✅ Автоматически добавляет в `.gitignore` и `.cursorignore`:
- Изображения (`.png`, `.jpg`, `.gif`, `.svg`, и т.д.)
- Видео (`.mp4`, `.mov`, `.avi`)
- Базы данных (`.sqlite`, `.db`)
- Архивы (`.zip`, `.rar`, `.7z`)
- Логи (`.log`)
- Исполняемые файлы (`.exe`, `.dll`, `.bin`)
- И другие "мусорные" файлы больше 1MB

### ✅ Автоматически удаляет из ignore-файлов:
- Записи для файлов, которые вы удалили с диска

### ✅ Блокирует коммиты:
- Если вы пытаетесь закоммитить код-файл больше 500KB

## 🆘 Решение проблем

### Команда `ghost` не найдена:

**Windows:**
```bash
# Добавьте путь к скриптам Python в PATH
# Или используйте:
python -m pip install --upgrade ghost-protocol
```

**Проверка установки:**
```bash
pip show ghost-protocol
```

### Ghost не работает:

1. Убедитесь, что вы в корне git-репозитория
2. Проверьте, что Python 3.8+ установлен
3. Переустановите: `pip install --upgrade ghost-protocol`

### Hook не устанавливается:

Убедитесь, что вы в git-репозитории:
```bash
git status
```

Если не git-репозиторий, инициализируйте:
```bash
git init
```

## 💡 Советы

1. **Запускайте ghost в отдельном терминале** - так он не будет мешать основной работе
2. **Используйте монитор периодически** - чтобы видеть статистику проекта
3. **Настройте конфиг под свой проект** - если нужны другие лимиты
4. **Не беспокойтесь о ignore-файлах** - Ghost управляет ими автоматически
