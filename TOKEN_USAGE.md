# Использование API токена PyPI

## Способ 1: Интерактивный ввод (проще для первой публикации)

При выполнении команды `python -m twine upload dist/*` вам будет предложено ввести:
- **Username**: `__token__`
- **Password**: ваш полный токен (начинается с `pypi-`)

Пример:
```
Enter your username: __token__
Enter your password: pypi-ВАШ_РЕАЛЬНЫЙ_ТОКЕН_ЗДЕСЬ_НАЧИНАЕТСЯ_С_pypi-
```

---

## Способ 2: Файл конфигурации .pypirc (удобнее для повторных загрузок)

### На Windows:

1. Создайте файл `.pypirc` в папке пользователя:
   - Путь: `C:\Users\ВашеИмя\.pypirc`
   - Или используйте переменную окружения: `%USERPROFILE%\.pypirc`

2. Содержимое файла `.pypirc`:

```ini
[pypi]
  username = __token__
  password = pypi-ВАШ_ТОКЕН_ЗДЕСЬ

[testpypi]
  username = __token__
  password = pypi-ВАШ_ТОКЕН_ДЛЯ_TESTPYPI_ЗДЕСЬ
```

**ВАЖНО**: Замените `ВАШ_ТОКЕН_ЗДЕСЬ` на ваш реальный токен (весь, включая префикс `pypi-`)

### Пример создания файла через командную строку (Windows):

```cmd
echo [pypi] > %USERPROFILE%\.pypirc
echo   username = __token__ >> %USERPROFILE%\.pypirc
echo   password = pypi-ВАШ_ТОКЕН_ЗДЕСЬ >> %USERPROFILE%\.pypirc
```

Или создайте файл вручную в блокноте и сохраните как `.pypirc` (без расширения) в папке `C:\Users\ВашеИмя\`

### После создания файла:

Twine автоматически будет использовать токен из файла, и вам не нужно будет вводить его каждый раз:

```bash
python -m twine upload dist/*
```

---

## Безопасность

⚠️ **ВАЖНО**: 
- Файл `.pypirc` содержит ваш токен в открытом виде
- Не коммитьте этот файл в git (добавьте `.pypirc` в `.gitignore`)
- Не делитесь этим файлом с другими
- Храните токен в безопасном месте

### Добавьте .pypirc в .gitignore:

```bash
echo .pypirc >> .gitignore
```

---

## Проверка работы

После настройки попробуйте:

```bash
# Проверка пакета
python -m twine check dist/*

# Загрузка (токен будет взят из .pypirc или запрошен интерактивно)
python -m twine upload dist/*
```

---

## Рекомендация

Для **первой публикации** используйте **Способ 1** (интерактивный ввод), чтобы убедиться, что всё работает.

Для **последующих обновлений** используйте **Способ 2** (файл .pypirc) для удобства.
