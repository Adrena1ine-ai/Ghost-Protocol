## 📦 Установка пакета:

```bash
pip install ghost-protocol
```

## 🚀 Использование:

После установки команда `ghost` будет доступна:

```bash
# Установка git hook
ghost --install

# Запуск фонового режима
ghost --ghost

# Открытие монитора
ghost --monitor
```
