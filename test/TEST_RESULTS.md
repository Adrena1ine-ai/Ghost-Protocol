## ⚠️ ИСПРАВЛЕННЫЕ ПРОБЛЕМЫ

### Проблема: DATA файлы не классифицировались правильно

**Проблема:**
- `test_data.csv (488KB)` не был добавлен в `.gitignore`
- Причина: проверка требовала размер > `max_asset_size_mb` (1MB), но файл был 488KB

**Решение:**
- Добавлен новый параметр `data_min_size_kb: 100` в конфиг
- Обновлена логика классификации DATA файлов:
  ```python
  # Теперь data файлы > 100KB и < 2MB классифицируются как DATA
  if size_kb > data_min_size_kb and size_mb <= max_trash_size_mb:
      return "DATA"
  ```

**Файлы изменены:**
- `src/config.py` - добавлен `data_min_size_kb` в DEFAULT_CONFIG и property
- `src/classifier.py` - обновлена логика проверки DATA расширений

## 📝 ЗАМЕТКИ

- Ghost Protocol работает как **файловый watcher**, не как git hook
- Он обнаруживает файлы при **создании/изменении** в файловой системе
- `git commit` сам по себе не триггерит Ghost (файл уже должен быть обработан)
- Debounce time: 0.5 секунды (настраивается в конфиге)
