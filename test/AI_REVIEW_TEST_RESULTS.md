## 🐛 ИЗВЕСТНЫЕ ПРОБЛЕМЫ

### Проблема 1: Git Diff для AI Review
**Описание**: `git diff HEAD` не показывает изменения после `git add`

**Решение**:
```python
# В ai_reviewer.py нужно изменить:
output = subprocess.check_output(
    ["git", "diff", "HEAD", "--unified=0"],  # Текущий код
    ...
)

# На один из вариантов:
output = subprocess.check_output(
    ["git", "diff", "--cached", "--unified=0"],  # Staged changes
    ...
)
# ИЛИ
output = subprocess.check_output(
    ["git", "diff", "HEAD~1", "--unified=0"],  # После коммита
    ...
)
```

### Проблема 2: Radon не находит сложность
**Описание**: Radon проверяет только верхнеуровневые директории

**Решение**:
```python
# В analyzer.py нужно передавать все подпапки:
target_dirs = []
for item in self.root.rglob("*"):
    if item.is_dir() and item.name not in cfg.skip_dirs:
        target_dirs.append(str(item))
```
